- 鉴权默认关闭（false），生产经环境变量开启。

## 3. 测试与缺陷状态

| 项 | 数值 |
|---|---|

| 缺陷 | D-01~D-07 **全部关闭**（CSV 引号、页面内联、删表空响应、时间戳乱序、空主键、valueAt 装箱、security 配置回归） |
| 已知问题 | K-01~K-04 **全部解决**（精确窗口、表级锁、UI 验证、百万行压测） |
| 性能基准 | 20 万行写入 414ms / 读取 342ms；批量 3×10 万行 90ms vs 逐条 224ms；百万行写入 1485ms / 读取 2558ms |
