- **变更 1（可空复选框生效）**：行为正确——勾选列真实写入 `nullable=true`（黑盒端到端还原 null 证明）、非空列空值 400 拒绝且不产生数据、主键列强制非空（页面提交收敛 + core 校验双保障）。前端复选框状态→请求体映射经走查确认（UI-F1/F2）。
